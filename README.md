## What's this?

My CTF and lab writeups. I write them the way I wish I'd found them when I started: no assumed knowledge, every command explained, and the mistakes left in, because that's where the real learning happens.

If you've ever opened a writeup and ended up with 15 tabs of googling, these are meant to fix that.
